# スカイライン・テクノロジーズ コーポレートサイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ株式会社（Skyline Technologies Inc.）」のコーポレートサイトです。
1ページで完結する静的サイトで、`index.html` だけで動作します。

> このサイトに登場する企業・人物・実績・連絡先はすべて架空のものです。

## サイトの概要

社名の「スカイライン」にちなみ、ビル群のシルエットと、セクションごとに高度が上がっていく見出し（`ALT 040m` → `ALT 240m`）をデザインの軸にしています。

### ページ構成

| セクション | 内容 |
| --- | --- |
| お知らせ | ナビゲーション直下に、日付・カテゴリ付きの最新情報を3件表示 |
| ヒーロー | キャッチコピーと、窓の明かりが点滅するビル群のシルエット |
| 事業内容 | 業務システム開発／クラウド基盤構築・運用／モバイルアプリ開発／AI・データ活用支援 |
| 導入事例 | 実績の数字（累計プロジェクト数など）と、物流・小売・製造の事例3件 |
| 開発の進め方 | ヒアリング・要件定義からリリース・運用までの4段階と標準期間 |
| 会社概要 | 社名・設立・所在地などの基本情報と代表メッセージ |
| 採用情報 | 募集職種と年収レンジ |
| お問い合わせ | 入力チェック付きのフォーム（デモのため実際には送信されません） |

### 特徴

- ライト／ダークテーマに対応（OS の設定に合わせて自動で切り替わります）
- スマートフォンの画面幅でも崩れないレスポンシブレイアウト
- 外部ライブラリなし。フォントのみ Google Fonts から読み込みます

```
campany-site/

```

## ブラウザで index.html を開く手順

ビルドやサーバーの準備は不要です。次のいずれかの方法で開いてください。

### 方法1：ファイルをダブルクリックする

1. エクスプローラー（Mac の場合は Finder）で `campany-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

別のブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」から選ぶか、ブラウザのウィンドウへドラッグ＆ドロップしてください。

### 方法2：ブラウザのアドレスバーにパスを入力する

ブラウザのアドレスバーにファイルのパスを入力して開くこともできます。

```
file:///D:/claudecode/campany-site/index.html
```

パスはリポジトリを置いた場所に合わせて読み替えてください。

### 方法3：コマンドで開く

ターミナルでリポジトリのフォルダに移動してから実行します。

```bash
# Windows（PowerShell / コマンドプロンプト）
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 表示されないときは

- フォントは Google Fonts から読み込むため、オフラインでは代替フォントで表示されます。レイアウトや機能には影響しません。
- 古いブラウザでは一部の表示が崩れる場合があります。Chrome・Edge・Firefox・Safari の最新版でご確認ください。
